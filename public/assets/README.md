# Runtime Assets

This folder contains image assets used by the Innrspark app at runtime.

- `/designs` remains the exported Figma reference source and should stay unchanged.
- `/public/assets` is the runtime-safe location for images imported or referenced by React components.
- Keep assets organized by product area:
  - `assessment`
  - `auth`
  - `career_recommendation`
  - `chat`
  - `onboarding`
  - `roadmap`

When adding new runtime images, place them in the matching category folder and keep file names descriptive.
