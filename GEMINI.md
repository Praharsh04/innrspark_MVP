## UI/UX Polish Mode (Strict)
You are doing surface-level UI/UX polish only.

### Strict rules:
- Do not change business logic.
- Do not change API calls.
- Do not change Supabase code.
- Do not change AI code.
- Do not change Zustand stores.
- Do not change assessment, recommendation, roadmap, or chatbot engines.
- Do not change TypeScript types or data contracts.
- Do not rename props unless absolutely necessary.
- Do not change route structure.
- Do not change authentication behavior.
- Do not change database schema.
- Do not add new dependencies.
- Do not delete existing functionality.

### Allowed changes:
- Tailwind class changes
- spacing
- typography
- colors within existing design system
- shadows
- borders
- border radius
- animations/transitions
- loading skeletons
- micro-interactions
- icon sizing
- responsive layout fixes
- visual hierarchy
- copy spacing/line breaks

If a requested visual change requires editing forbidden files, stop and explain why.
